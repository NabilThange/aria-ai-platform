## 📂 Pick ONE Category — Each Has Mandatory Tech

### 🗣️ Live Agents
- **Focus:** Real-time audio/vision interaction (interruptible)
- **Mandatory Tech:** Gemini **Live API** or **ADK**
- Examples: real-time translator, vision-enabled tutor, voice support agent

### ✍️ Creative Storyteller
- **Focus:** Multimodal storytelling with interleaved output
- **Mandatory Tech:** Gemini's **interleaved/mixed output capabilities**
- Examples: interactive storybook, marketing asset generator, educational explainer

### ☸️ UI Navigator
- **Focus:** Visual UI understanding & screen interaction
- **Mandatory Tech:** Gemini **multimodal** to interpret screenshots/screen recordings + output executable actions
- Examples: web navigator, cross-app workflow automator, visual QA testing agent

## 💛 What Would Judges LOVE

> Judging is split: **40% UX/Innovation | 30% Technical | 30% Demo & Presentation**

### 🚀 Innovation & Multimodal UX (40%) — Make Them Go "Wow"
- **Shatter the text box** — if your app feels like a chatbot, it won't score well
- Build something that truly **Sees 👁️, Hears 👂, and Speaks 🗣️** seamlessly
- Give your agent a **distinct personality and voice** — not a generic assistant
- Make the experience feel **live and context-aware**, not turn-based or robotic
- **Category-specific gold:**
  - *Live Agent:* Natural barge-in/interruption handling — fluid like a real conversation
  - *Storyteller:* Text, image, audio, and video woven together in **one cohesive stream**
  - *UI Navigator:* Agent that truly **understands screen context**, not just blindly clicking

### 🔧 Technical Execution (30%) — Show You Know Your Stack
- Use **Google GenAI SDK or ADK properly** — judges will read your code
- Host on **Cloud Run, Vertex AI, or Firestore** — be explicit about it
- Handle **errors, API timeouts, and edge cases gracefully**
- Show **grounding** — agents that hallucinate less score more
- Clean, well-structured **agent logic**

### 🎬 Demo & Presentation (30%) — Sell It
- Tell a **clear story**: problem → solution → impact
- Show the software **actually working live** — judges are skeptical of mockups
- Make the **architecture diagram clean and easy to read** — put it front and center
- Include **visual proof of GCP deployment** in the video or submission
- Keep it tight — **under 4 minutes**, every second counts
