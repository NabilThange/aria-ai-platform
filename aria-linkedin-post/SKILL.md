# LinkedIn Post Publishing via N8N Webhook

## What is This?

This skill teaches OpenCode how to publish LinkedIn posts via an N8N webhook integration. The workflow extracts a LinkedIn post from a markdown file (generated by Perplexity AI) and sends it to LinkedIn through an automated N8N pipeline.

**Flow:**
```
Perplexity Research → Markdown Export → OpenCode Extraction → N8N Webhook → LinkedIn API → Published Post
```

---

## Prerequisites

1. **N8N Webhook URL**: `https://n8n-render-tpfk.onrender.com/webhook/aria-linkedin`
2. **Markdown File**: Contains research + LinkedIn post (usually in `/home/user/Desktop/` or `/home/user/Downloads/`)
3. **LinkedIn Credentials**: Configured in N8N (OAuth token or API key)

---

## Step-by-Step Process

### Step 1: Find the Markdown File

The markdown file is auto-downloaded from Perplexity with this naming pattern:
- `Aria_Research_*.md`
- Created within the last 5 minutes
- Located in `/home/user/Desktop/` or `/home/user/Downloads/`

**Commands to find it:**
```bash
# Check Desktop first (most common)
ls -lt /home/user/Desktop/*.md | head -3

# Check Downloads as fallback
ls -lt /home/user/Downloads/*.md | head -3

# Search by modification time (last 5 minutes)
find /home/user -name "*.md" -type f -mmin -5

# Search by name pattern
find /home/user -name "Aria_Research_*.md" -type f
```

**Example output:**
```
-rw-r--r-- 1 user user 8432 Apr  4 14:23 /home/user/Desktop/Aria_Research_AI_in_Healthcare.md
```

### Step 2: Read and Parse the File

The markdown file has this structure:

```markdown
# AI in Healthcare

> **Exported by Aria Research**  
> Date: April 4, 2026, 2:23 PM  
> Source: https://www.perplexity.ai/...

---

## 🧑 Query 1

You are a professional content research assistant. Research the topic "AI in Healthcare" thoroughly...

## 🤖 Answer

[RESEARCH CONTENT - 500+ words with citations]

### 📚 Sources

[1] Healthcare AI Report 2026  
<https://example.com/report>

---

## 🧑 Query 2

Based on your research above about "AI in Healthcare", write a professional LinkedIn post...

## 🤖 Answer

🏥 Is AI really transforming healthcare, or is it just hype?

After diving deep into the latest research, here's what's actually happening:

✅ AI diagnostics are now matching radiologist accuracy in 87% of cases
✅ Predictive models are reducing hospital readmissions by 23%
✅ Drug discovery timelines cut from 10 years to 18 months

But here's the catch: implementation costs and data privacy remain major barriers.

The future? Hybrid human-AI teams, not replacement.

What's your take on AI in your healthcare experience?

#HealthTech #ArtificialIntelligence #DigitalHealth #Innovation #FutureOfMedicine

---
```

**What to extract:**
- The **LAST** `## 🤖 Answer` section (this is the LinkedIn post)
- Everything from that heading until the next `---` or end of file
- Keep hashtags, emojis, and line breaks

---

### Step 3: Extract the LinkedIn Post

**Using grep + sed:**
```bash
# Extract everything after the last "## 🤖 Answer"
LINKEDIN_POST=$(tac /home/user/Desktop/Aria_Research_AI_in_Healthcare.md | \
  sed -n '/## 🤖 Answer/,/---/p' | \
  tac | \
  sed '1d;$d' | \
  sed 's/^## 🤖 Answer$//' | \
  sed '/^$/d' | \
  head -c 3000)

echo "$LINKEDIN_POST"
```

**Using awk (more reliable):**
```bash
# Find the last occurrence of "## 🤖 Answer" and extract until "---"
awk '/## 🤖 Answer/ {flag=1; buffer=""; next} 
     flag && /^---$/ {flag=0} 
     flag {buffer=buffer $0 "\n"} 
     END {print buffer}' /home/user/Desktop/Aria_Research_AI_in_Healthcare.md
```

**Using Python (most robust):**
```bash
python3 << 'EOF'
import re

with open('/home/user/Desktop/Aria_Research_AI_in_Healthcare.md', 'r') as f:
    content = f.read()

# Find all "## 🤖 Answer" sections
sections = re.split(r'## 🤖 Answer', content)

if len(sections) >= 2:
    # Get the last answer section
    last_answer = sections[-1]
    
    # Extract until "---" or end
    post = re.split(r'\n---', last_answer)[0].strip()
    
    # Clean up
    post = post.replace('### 📚 Sources', '').strip()
    
    print(post)
else:
    print("ERROR: No LinkedIn post found")
EOF
```

### Step 4: Send to N8N Webhook

**Correct Syntax:**
```bash
curl -X POST "https://n8n-render-tpfk.onrender.com/webhook/aria-linkedin" \
  -H "Content-Type: application/json" \
  -d '{
    "post": "🏥 Is AI really transforming healthcare...\n\n#HealthTech #AI",
    "topic": "AI in Healthcare"
  }' \
  && echo "✅ LINKEDIN_SUCCESS"
```

**With proper JSON escaping:**
```bash
# Store post in variable
LINKEDIN_POST="🏥 Is AI really transforming healthcare, or is it just hype?

After diving deep into the latest research, here's what's actually happening:

✅ AI diagnostics are now matching radiologist accuracy in 87% of cases

#HealthTech #ArtificialIntelligence"

# Escape for JSON (replace newlines, quotes, etc.)
ESCAPED_POST=$(echo "$LINKEDIN_POST" | python3 -c 'import json, sys; print(json.dumps(sys.stdin.read()))')

# Send to webhook
curl -X POST "https://n8n-render-tpfk.onrender.com/webhook/aria-linkedin" \
  -H "Content-Type: application/json" \
  -d "{\"post\": $ESCAPED_POST, \"topic\": \"AI in Healthcare\"}" \
  && echo "✅ LINKEDIN_SUCCESS"
```

**Using jq for perfect JSON:**
```bash
LINKEDIN_POST=$(cat extracted_post.txt)
TOPIC="AI in Healthcare"

jq -n \
  --arg post "$LINKEDIN_POST" \
  --arg topic "$TOPIC" \
  '{post: $post, topic: $topic}' | \
curl -X POST "https://n8n-render-tpfk.onrender.com/webhook/aria-linkedin" \
  -H "Content-Type: application/json" \
  -d @- \
  && echo "✅ LINKEDIN_SUCCESS"
```

## Complete One-Liner Script

```bash
#!/bin/bash

# Find the most recent Aria Research markdown file
FILE=$(find /home/user -name "Aria_Research_*.md" -type f -mmin -10 -printf '%T@ %p\n' | sort -rn | head -1 | cut -d' ' -f2)

if [ -z "$FILE" ]; then
  echo "❌ ERROR: No markdown file found"
  exit 1
fi

echo "📄 Found file: $FILE"

# Extract LinkedIn post (last ## 🤖 Answer section)
LINKEDIN_POST=$(python3 << EOF
import re
with open('$FILE', 'r') as f:
    content = f.read()
sections = re.split(r'## 🤖 Answer', content)
if len(sections) >= 2:
    last_answer = sections[-1]
    post = re.split(r'\n---', last_answer)[0].strip()
    post = re.split(r'### 📚 Sources', post)[0].strip()
    print(post)
EOF
)

if [ -z "$LINKEDIN_POST" ]; then
  echo "❌ ERROR: Could not extract LinkedIn post"
  exit 1
fi

echo "📝 Extracted post (${#LINKEDIN_POST} chars)"

# Extract topic from filename
TOPIC=$(basename "$FILE" .md | sed 's/Aria_Research_//' | sed 's/_/ /g')

echo "🎯 Topic: $TOPIC"

# Send to N8N webhook
RESPONSE=$(jq -n \
  --arg post "$LINKEDIN_POST" \
  --arg topic "$TOPIC" \
  '{post: $post, topic: $topic}' | \
curl -s -X POST "https://n8n-render-tpfk.onrender.com/webhook/aria-linkedin" \
  -H "Content-Type: application/json" \
  -d @-)

echo "📡 Webhook response: $RESPONSE"
echo "✅ LINKEDIN_SUCCESS"
```

## Common Errors & Fixes

### ❌ Error: "No markdown file found"

**Cause:** File not in expected location or too old

**Fix:**
```bash
# Check all possible locations
find /home/user -name "*.md" -type f -mmin -30 -ls

# Manually specify file path
FILE="/home/user/Downloads/Aria_Research_Topic.md"
```

---

### ❌ Error: "Could not extract LinkedIn post"

**Cause:** Markdown structure doesn't match expected format

**Fix:**
```bash
# Debug: Show all "## 🤖 Answer" sections
grep -n "## 🤖 Answer" "$FILE"

# Manually extract by line numbers
sed -n '150,200p' "$FILE"  # Adjust line numbers
```

---

### ❌ Error: "curl: (3) URL malformed"

**Cause:** Unescaped special characters in JSON

**Wrong:**
```bash
curl -d '{"post": "Text with "quotes" and newlines"}'
```

**Right:**
```bash
# Use jq for automatic escaping
jq -n --arg post "$TEXT" '{post: $post}'
```

---

### ❌ Error: "N8N webhook returns 400 Bad Request"

**Cause:** Invalid JSON format

**Debug:**
```bash
# Test JSON validity before sending
echo '{"post":"test","topic":"test"}' | jq .

# Check what you're actually sending
jq -n --arg post "$LINKEDIN_POST" '{post: $post}' | cat -A
```

---

### ❌ Error: "Post truncated or missing hashtags"

**Cause:** Extraction stopped too early

**Fix:**
```bash
# Ensure you capture until "---" not "###"
awk '/## 🤖 Answer/ {flag=1; next} 
     flag && /^---$/ {exit} 
     flag {print}' "$FILE"
```

## N8N Webhook Expected Payload

```json
{
  "post": "🏥 Is AI really transforming healthcare...\n\n#HealthTech #AI",
  "topic": "AI in Healthcare"
}
```

**N8N should:**
1. Receive webhook POST request
2. Extract `post` and `topic` fields
3. Authenticate with LinkedIn API (OAuth)
4. Call LinkedIn API: `POST /v2/ugcPosts`
5. Return success/error response

---

## LinkedIn API Reference (for N8N)

**Endpoint:**
```
POST https://api.linkedin.com/v2/ugcPosts
```

**Headers:**
```
Authorization: Bearer {ACCESS_TOKEN}
Content-Type: application/json
X-Restli-Protocol-Version: 2.0.0
```

**Body:**
```json
{
  "author": "urn:li:person:{PERSON_ID}",
  "lifecycleState": "PUBLISHED",
  "specificContent": {
    "com.linkedin.ugc.ShareContent": {
      "shareCommentary": {
        "text": "🏥 Is AI really transforming healthcare...\n\n#HealthTech"
      },
      "shareMediaCategory": "NONE"
    }
  },
  "visibility": {
    "com.linkedin.ugc.MemberNetworkVisibility": "PUBLIC"
  }
}
```
